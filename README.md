# Midcap + Smallcap Kite Live Research Scanner

A research-first Streamlit dashboard for the **Nifty Midcap 150 + Nifty Smallcap 250** universe, using **Kite Connect** for broker-grade NSE data.

## Architecture

```text
NSE Indices constituents
        ↓
Nifty Midcap 150 + Smallcap 250
        ↓
Kite NSE EQ instrument mapping
        ↓
Kite daily historical candles
        ↓
Trend / momentum / breakout / liquidity research score
        ↓
KiteTicker WebSocket live layer
        ↓
LTP / day change / VWAP / live momentum
        ↓
Research ranking
```

## Authentication

For Streamlit Community Cloud, store these in **Settings → Secrets**:

```toml
KITE_API_KEY = "your_api_key"
KITE_API_SECRET = "your_api_secret"
```

Every morning, paste the `request_token` generated by your Kite Connect login redirect into the sidebar and click **Authenticate**. The app exchanges it for an `access_token` using Kite Connect's official session flow. Alternatively, an access token can be pasted directly.

Do **not** commit the API secret, access token, or request token to GitHub.

## Live data

The live layer uses `KiteTicker` WebSocket and subscribes to the mapped Midcap + Smallcap universe. Kite Connect currently supports up to 3,000 instruments per WebSocket connection, so the ~400-stock universe fits comfortably within one connection. citeturn1search6turn1search11

REST quote and historical endpoints are deliberately not polled continuously. Kite documents/communicates a 1 request/sec quote limit and 3 requests/sec historical limit; WebSocket is the appropriate mechanism for continuous live data. citeturn1search0turn1search4

## Research model

The original strategy is retained:

1. SMA150 > EMA220
2. Close > SMA50
3. SMA50 > SMA150
4. Close > 1.25 × prior 252-day low
5. Low dipped below EMA220 during the prior 90 sessions
6. Close > prior 252-day highest close

Additional research factors:

- 5D / 20D / 60D momentum
- Relative volume
- Average traded value
- ATR / ATR%
- Trend alignment
- Breakout confirmation
- Liquidity gating
- ResearchScore
- ATR-aware stop reference
- Position sizing reference
- Live VWAP relationship
- Live day-change momentum

## Important

This version intentionally contains **no automatic order-placement code**. It is a research/scanning system; execution remains manual unless a separate, explicitly tested execution module is added.
